# homelab

Notes and configs from learning self-hosting on Fedora with Podman.

## Services 

### Uptime Kuma ('uptime-kuma/')
A tool that checks whether websites are online.

To start it:
	bash uptime-kuma/run.sh

Then, open http://localhost:3001
